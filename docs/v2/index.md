# InvoiceShelf 2 documentation

This collection describes **InvoiceShelf 2.4.6**. Use the version selector to keep the instructions and screenshots aligned with the application you run.

Version 2 is the stable maintenance line. It receives security fixes through **1 September 2027**; new product development is on v3.

## Start here

1. [Install InvoiceShelf](./installation.md), then finish the browser setup wizard.
2. Check your [company and account settings](./guide/settings.md).
3. Add [customers](./guide/customers.md) and reusable [items](./guide/items.md).
4. Create an [estimate](./guide/estimates.md) or [invoice](./guide/invoices.md), then [record payments](./guide/payments.md).
5. Review [expenses](./guide/expenses.md) and [reports](./guide/reports.md).

## Find the right guide

The sidebar and keyword search are restricted to this version. AI answers are available in the v3 documentation only; v2 keyword search remains available. If a topic exists only in the other version, switching versions takes you to that collection’s overview instead of showing mismatched instructions.

The screenshots use isolated demonstration data from this release. Names, totals and dates in your installation will differ.
