# Items

The item catalog saves frequently used products and services so you can select them on invoices and estimates. Open **Items** in the company sidebar.

## Add an item

1. Select **Add Item** from the item list.
2. Enter a **Name**, **Price**, **Unit** and optional **Description**.
3. Select **Save Item**.

![InvoiceShelf 2 item form](/images/v2/item-create.webp)

Use a descriptive name such as “Website development” and a unit that matches how you charge. An item price is a starting value: check the quantity, price, taxes and discount on each sales document before saving it.

## Use the catalog

Select an item in an invoice or estimate line to populate its details, then adjust the line for that job. Use **Add New Item** in the document form when you need another line. Document totals are calculated from the lines and document settings.

![InvoiceShelf 2 reusable item catalog](/images/v2/items.webp)

The item list provides filtering and row actions for editing or deleting entries when your role permits it. Update catalog values for future work; do not assume that editing an item will rewrite existing invoices.

See [Invoices](./invoices.md), [Estimates](./estimates.md) and [Tax types](./taxes.md).
