# Members and roles

Company membership determines which people can work in the selected company. Global user administration is a separate administrator function.

## Add access

Open **Members** and use **Add Member** or **Invite Member**, depending on whether you are adding an existing user or inviting someone. Review the company and role before completing the form. An invitation requires working email delivery.

![InvoiceShelf 3 company members](/images/v3/members.webp)

## Define permissions

Open **Settings → Company Roles**. The owner role is a system role; presets such as Manager and Read only provide starting permissions. Use **Add New Role** for a company-specific set of abilities. Global role presets are managed under Administration.

![InvoiceShelf 3 role settings](/images/v3/roles.webp)

## Check the result

Sign in as the person or a dedicated test user and verify that the required pages and actions are available. A hidden navigation entry and a rejected action often indicate a missing permission or the wrong selected company. Removing staff access should also include reviewing any integrations or credentials that person controlled.
