# InvoiceShelf 3 documentation

This collection describes **InvoiceShelf 3.0.0-alpha.10**. Use the version selector to keep the instructions and screenshots aligned with the application you run.

Version 3 is the latest product line and is currently an **alpha preview**. Test with disposable data or a separate copy of your installation. Use the stable v2 release for production invoicing.

## Start here

1. [Install InvoiceShelf](./installation.md), then finish the browser setup wizard.
2. Check your [company and account settings](./guide/settings.md).
3. Add [customers](./guide/customers.md) and reusable [items](./guide/items.md).
4. Create an [estimate](./guide/estimates.md) or [invoice](./guide/invoices.md), then [record payments](./guide/payments.md).
5. Review [expenses](./guide/expenses.md) and [reports](./guide/reports.md).

## Find the right guide

The sidebar and keyword search are restricted to this version. Ask AI answers from reviewed v3 guides and links to the sections it used. If a topic exists only in the other version, switching versions takes you to that collection’s overview instead of showing mismatched instructions.

The screenshots use isolated demonstration data from this release. Names, totals and dates in your installation will differ.
