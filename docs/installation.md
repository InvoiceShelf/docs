# Installation

This guide covers the supported InvoiceShelf 2.x release. InvoiceShelf 3.x is
still an alpha preview and should not be used with production data.

InvoiceShelf can be installed with Docker Compose or manually. For most self-hosted
installations, we recommend Docker Compose because the supported production images and
database variants are maintained in one place.


## Docker Installation

Use the official production Compose repository and choose SQLite, MariaDB, or PostgreSQL.

[[Learn More]](./install/docker.md)

## Manual Installation

Use this option when you manage PHP, the web server, and the database yourself.
